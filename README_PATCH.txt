LubaNote – SVG ikony mobil + APK + desktop v3

Nahraď / přidej tyto soubory:
- index.html
- lubaIcons.js        (NOVÝ – centrální SVG knihovna pro celou app)
- desktopIcons.js     (nově jen desktopové napojení sidebaru)
- script.js           (SVG stavové ikony na kartách)
- cardView.js         (SVG GRID/LIST)
- style.css           (společné styly ikon + stejné 3 moduly v APK)
- desktop.css         (desktopové styly napojené na centrální SVG)

Volitelný návod:
- LUBANOTE_SVG_IKONY_NAVOD.md

Uživatelské barevné štítky (code, LubaNote, projekt...) zůstávají čisté bez ikon.
SVG dostaly systémové filtry, navigace a stavové ikony karet.
